# Contributing

Useful contributions include a small scene that refuses unexpectedly, an independently checked geometric counterexample, or a concrete improvement to a complete user journey. Include the scene, expected result, Python/browser version and work budget. Please avoid adding automatic cloud services or turning sampled raster checks into continuous guarantees.

Run the Python and Node commands in the README. Core checks must work without the optional native renderer; graphics tests must identify the actual renderer, font and backend. Preserve existing files and use new output destinations.

AI assistance is welcome when disclosed and reviewed by the person submitting it. Do not fabricate observations, benchmark results, authorship or endorsements. Follow the policies of any upstream project before contacting it.
