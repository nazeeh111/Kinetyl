# Validation scope

Before publication, the source is checked with independent rational critical-time oracles, Python/JavaScript normalization and plan parity, malformed and forged plan controls, resource-budget refusals, no-clobber output checks and an installed-wheel journey. Browser controls exercise edits, recovery, imports, aspect changes and downloads.

The eigenvalue example was measured with ManimGX 0.1.1 and Noto Sans. Native wide (960×540) and portrait (540×960) runs each inspected 145 object-ID frames and produced 145 normal-color pixel callbacks at 24 fps. Each dual pass charged 150,336,000 pixels. Wide uses scale 4/5; portrait uses 3/5. World trajectories and event times remain unchanged. Each receipt contains per-frame boxes, source identity, video hash and a four-pixel native correspondence tolerance. These are bounded observed results, not continuous raster or comprehension guarantees.

The source examples include five keyframes for each of three objects. Eigenvalues are exact affine branches; determinant values are exact only at their five samples and linearly interpolated between them. Native GPU checks are separate from hosted dependency-free tests. Hosted CI does not certify a GPU backend or replay the native rendering automatically.

No universal reverse engineering, new mathematical theory, speedup over another renderer, outside adoption or security advisory credit is claimed.
