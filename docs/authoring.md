# Author a path and keep the exact source

Import a supported measured scene or verified plan in the studio. Enable **Edit paths**. Select an object/keyframe or segment/control in the point list, or select its handle in the world plot. Endpoints are shared by their adjacent segments; editing an endpoint changes that stored point only. No linked controls or times are inferred.

Drag on the disclosed 1/20 world-unit grid. Focus a handle and use arrow keys for exact 1/20 steps on one axis, retaining the other coordinate exactly. Exact x/y fields accept integers, decimals and fractions such as 7/3. Apply the point or press Enter; Cancel/Escape restores uncommitted fields or a pointer drag. Undo/Redo reverses committed path changes. Untouched rational coordinates, label envelopes and times are retained.

The world view is independent of the layout camera and remains fixed through edits and canvas changes. Extreme valid points can leave its visible bounds; use the point list and exact fields or **Fit draft to view**. Fit changes the view only. The plotted coordinates are approximate drawing values; saved coordinates and verification use exact rationals.

The JSON path source and visual controls share a draft. Pending JSON, including invalid/incomplete text, blocks visual edits. Choose **Apply JSON to draft** or **Discard JSON text** explicitly. Coordinate fields must likewise be applied/cancelled before compilation. No callback, imported code or external service executes.

**Compile draft paths** uses the existing bounded layout search and independent verification. Pending or failed edits disable both verified downloads. The previous verified document remains visible. Undo can recover earlier path edits; **Restore imported original** returns to the imported source and clears path history. Save a failed draft before restoring if you want to retain it. NoSolution concerns the finite family; budget exhaustion is inconclusive. **Save source draft · unverified** exports valid, resolved draft data as `kinetyl-unverified-draft.scene.json`; it does not export a current verified layout or authenticate measurements. Invalid pending JSON/coordinates cannot be saved through this action. Reimporting a draft attempts compilation again under the same unchanged limits.

A frozen root-authored two-track/three-segment storyboard retained an untouched `9007199254740993/9007199254740992` control. The specified four-coordinate edit was structurally valid but exhausted the default 250000 work budget before a wide plan. That input was not tuned or retried with a larger budget. This is limiting evidence, not a successful independent authoring/export case. A separate positive example edits the shipped owned arch's first control y to 3/2; it is a supported illustration, not external demand.

Path editing deliberately changes authored motion. Do not move measured scientific data to avoid a presentation collision while claiming its meaning was preserved. Compilation itself continues to preserve the chosen source paths/timing and measured geometry, changing only supported label placement/framing. Current authoring exposes existing endpoints/controls; text measurement, timing/easing, general camera motion and arbitrary node construction are outside this UI.
